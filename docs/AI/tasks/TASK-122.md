- **所属模块**: `web`

---

## 2. 任务目标
打造基于 WebGL / Three.js 的前端交互式 2.5D 舞台画布编辑器。创作者可在浏览器/桌面端以 60fps 流畅帧率实时预览动画场景，使用鼠标直接拖拽角色微调站位、五槽位吸附、缩放以及朝向翻转。

---

## 3. 详细设计与实现要求
1. **Three.js 前端视口集成 (`web/src/components/StageCanvas.vue`)**:
   - 在 Vue 3 / Vite 环境中挂载 `ThreeStage`。
   - 响应式处理窗口尺寸调整，保持 16:9 画布比例。
2. **光线投射与交互操控 (`web/src/composables/useStageInteractions.ts`)**:
   - 使用 `THREE.Raycaster` 拾取角色部件。
   - 鼠标拖拽平移角色，释放时自动吸附至最近的标准舞台槽位（5 大槽位）。
   - 选中角色显示控制把手（朝向翻转按钮、缩放滑块、深度 Z-Index 调整）。
3. **实时 60fps 动效预览控制**:
   - 支持播放/暂停当前分镜的动作与摄像机运镜。
4. **组件测试 (`web/tests/stage_canvas.test.ts`)**:
   - 验证挂载、角色添加与槽位吸附响应。

---
