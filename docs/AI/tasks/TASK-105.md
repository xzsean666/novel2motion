## 2. 任务目标
组织并标准化 `assets/` 目录下的内置免版权资产包（韩天尊成男飞行立绘部件、魔道老祖部件、哮天鸡、天劫雷云界 2.5D 背景、马善政毛笔行楷字体、多轨情绪 BGM 与打斗 SFX 音效），实现开箱即用的自动导入与校验。

## 3. 详细设计与实现要求
1. **资产清单结构 (`assets/manifest.json`)**:
   - 包含角色（`characters`）、背景（`backgrounds`）、BGM（`bgm_library`）、音效（`combat_sfx_library`）、字体（`fonts`）。
2. **资产自动装载器 (`src/assets/asset-loader.ts`)**:
   - 启动时自动扫描并校验 `assets/` 目录文件的完整性与格式。
   - 自动批量写入 `CharacterRegistry` 与 `BackgroundRegistry`。
3. **单元测试 (`tests/builtin_assets.test.ts`)**:
   - 验证素材清单加载、缺失检测与数据库注入。
