# TASK-119: 单文件工程归档持久化与导入导出

## 1. 任务元数据
- **任务 ID**: TASK-119
- **状态**: DONE
- **优先级**: P1
- **所属模块**: `src/core`
- **依赖任务**: TASK-102, TASK-103

---

## 2. 任务目标
实现小说动画工程单文件归档规范（`.n2m`）。能够将整个动画项目（包含工程配置、角色立绘、背景图像、音频素材、时间轴分镜数据）打包为可分发的单个压缩文件，并支持跨机器、跨环境解压导入与版本校验。

---

## 3. 详细设计与实现要求
1. **归档规范定义 (`src/core/archive.ts`)**:
   - `.n2m` 文件内部结构：
     - `project.json`: 核心工程与时间轴元数据。
     - `assets/characters/`: 所用角色贴图与部件。
     - `assets/backgrounds/`: 所用背景图像。
     - `assets/audio/`: 音频与配音文件。
2. **打包与解包实现 (`src/core/project-packager.ts`)**:
   - 导出：一键归档当前工程为 `project.n2m`。
   - 导入：校验版本兼容性与 SHA256 哈希完整性，解包并恢复至 `KVDB` 数据库。
3. **单元测试 (`tests/project_archive.test.ts`)**:
   - 验证工程打包、解包恢复、跨版本兼容性检测。

---

## 4. 验收标准
- [ ] 成功实现 `.n2m` 单文件工程打包与无损解包恢复。
- [ ] 单元测试 100% 通过。
