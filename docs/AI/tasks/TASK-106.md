# TASK-106: 立绘自动抠图、透明通道处理与包围盒裁剪管线

## 1. 任务元数据
- **任务 ID**: TASK-106
- **状态**: DONE
- **优先级**: P1
- **所属模块**: `src/assets`
- **依赖任务**: TASK-102

---

## 2. 任务目标
构建专业的 2D 立绘自动抠图与尺寸标准化管线（`MattingPipeline`）。当创作者上传新角色立绘或 AI 生成新立绘时，自动清除纯色背景（漫水填充/色度抠图）、计算非透明像素紧凑包围盒、校准角色脚底/中心锚点并保存为标准化 PNG。

---

## 3. 详细设计与实现要求
1. **自动抠图核心 (`src/assets/matting-pipeline.ts`)**:
   - 支持纯白/纯黑/绿幕背景检测。
   - 采用边缘漫水填充算法，保留角色内部白色皮肤/牙齿/眼白不透明度，只去除外部背景。
2. **包围盒自动裁剪与锚点对齐 (`src/assets/bbox-cropper.ts`)**:
   - 计算非透明区域包围盒（Bounding Box），裁剪多余空白边距。
   - 自动推导标准锚点（站立角色底边居中 `anchor = (0.5, 1.0)`，飞行角色几何中心 `(0.5, 0.5)`）。
3. **单元测试 (`tests/matting_pipeline.test.ts`)**:
   - 测试纯白背景抠图、内部不透明保留与包围盒计算准确性。
