# TASK-117: 分镜独立哈希增量渲染缓存与毫秒级快速拼接器

## 1. 任务元数据
- **任务 ID**: TASK-117
- **状态**: DONE
- **优先级**: P1
- **所属模块**: `src/renderer`
- **依赖任务**: TASK-104

---

## 2. 任务目标
构建分镜级独立增量渲染缓存机制（`SceneRenderCache`）。根据分镜内容（背景、角色立绘、动作、台词音频、字幕）计算 SHA-256 内容哈希。若分镜内容未变则 100% 命中缓存跳过重渲；若仅修改个别镜头，仅重新渲染修改部分并由 FFmpeg 进行毫秒级无缝拼接（Concat）。

---

## 3. 详细设计与实现要求
1. **内容哈希敏感性模型 (`src/renderer/scene-hasher.ts`)**:
   - 提取分镜所有输入源计算确定性 Hash：背景图哈希 + 角色配置哈希 + 时间轴事件 + 台词音频哈希。
2. **分镜视频缓存管理器 (`src/renderer/scene-cache.ts`)**:
   - 缓存目录管理与元数据 JSON 记录。
   - 缓存命中时直接提供预渲染的小分镜视频文件（`scene_xxx.mp4`）。
3. **FFmpeg 极速视频流拼接 (`src/renderer/scene-concat.ts`)**:
   - 生成 FFmpeg concat 文件清单。
   - 使用 `-c copy` 极速完成多镜头合成为最终成品 MP4，零重编码损耗。
4. **单元测试 (`tests/scene_cache.test.ts`)**:
   - 验证哈希敏感性、缓存命中跳过与拼接逻辑。

---

## 4. 验收标准
- [ ] 未修改的分镜能够 100% 命中缓存跳过重渲。
- [ ] 拼接后的视频画质完整无卡顿黑帧。
- [ ] 单元测试 100% 通过。
