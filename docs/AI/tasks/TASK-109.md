# TASK-109: AI 导演高层分镜编排器与打斗配对状态机

## 1. 任务元数据
- **任务 ID**: TASK-109
- **状态**: DONE
- **优先级**: P0
- **所属模块**: `src/ai`
- **依赖任务**: TASK-108

---

## 2. 任务目标
实现智能高层分镜编导器（`AiDirector`）。将小说剧情事件编排为结构化分镜 DSL（`ScenePlan`），完成舞台站位规划、对峙朝向对齐、打斗攻防动作配对、情绪推断与 BGM 情绪匹配。

---

## 3. 详细设计与实现要求
1. **智能站位与镜头编排 (`src/ai/ai-director.ts`)**:
   - 单人分镜居中（`Center`）。
   - 双人对话对峙（`Left` 与 `Right`，互相对视：`Facing::Right` 与 `Facing::Left`）。
   - 三人/多人分镜自动分配 `FarLeft`、`Center`、`FarRight`。
2. **打斗攻防动作自动配对 (`src/ai/combat-director.ts`)**:
   - 识别攻击动作（如挥剑）生成 `Action::Attack`。
   - 紧随生成对方受击动作 `Action::Hit`，附带受击后仰、屏幕震动与白闪标记。
3. **情绪与表情推导 (`src/ai/emotion-resolver.ts`)**:
   - 识别震惊、恐惧、大惊失色关键词，自动将角色表情置为 `Shocked`（触发魔性人脸贴图）。
   - 匹配情绪 BGM（激战、悬疑、日常）。
4. **单元测试 (`tests/ai_director.test.ts`)**:
   - 验证分镜生成、攻防对齐与动作事件完整性。
