## 1. 背景与问题诊断 (Context & Diagnosis)

用户反馈当前生成的视频质量低、画面僵硬、各种瑕疵导致无法观看，并明确指出 Three.js 具备实现优秀动画效果的潜力。通过全片抽帧与渲染管线排查，定位到以下核心致命问题：
1. **画面中心突兀绿方块 Bug**: `HeadlessRenderer` 遍历 `THREE.Points` 未过滤非活跃点与深度，导致所有未激活粒子在 (0, 0, 0) 处被强制渲染为一个 8x8 发光绿色方块。
2. **受击白闪变成全屏灰雾 Bug**: `ScreenFlashQuad` 在暗色背景上使用普通 Alpha 绘制白色矩形，混合后导致全屏严重发灰发蒙；必须改用 Additive (`screen` / `lighter`) 强光爆闪混合。
3. **镜头极度呆板几乎不动**: `frameSpeaker` 被硬编码限制在 1.08 / 1.15 极小缩放，且平移仅偏离 38%，导致人物从头到尾只是屏幕边缘的微小纸片，缺乏特写、中景与戏剧性张力。
4. **角色动作与生命力不足**: 角色缺乏浮空呼吸律动（仅 2px 微动），缺少御剑飞行喷射尾光与魔道紫气，缺乏攻击前摇聚气蓄力、高速突进残影与受击顿挫回弹。
5. **法术特效单薄粗糙**: 雷霆仅为一条简单折线；剑阵仅为单薄折线多边形；近身斩击缺乏呼啸而过的月牙剑气波与飞溅火花。
6. **场景缺乏 3D 纵深与空间质感**: 缺少多层景深视差、环境灵气光尘、前景飘逸流云仙雾与电影级暗角。
7. **字幕缺乏国风推文爆款质感**: 黑色方块衬底呆板，缺少说话人阵营流光标签与进场卡点微冲击。

## 2. 修改前计划 (Execution Plan)

1. **修复严重渲染 Bug**:
   - 彻底解决中心绿色方块问题（活跃状态与透明度校验，发光柔和光晕）。
   - 修复受击闪烁（Additive 混合模式，高亮电光爆闪与指数衰减）。
2. **重构 Three.js 2.5D 多层景深与环境系统**:
   - 远景天穹视差联动。
   - 空间漂浮灵气光尘（28-36 粒自然上升与风向晃动）。
   - 前景流云仙雾层（半透明白雾自边缘缓缓飘移，提供真实 3D 纵深感）。
   - 电影级暗角（Vignette）强化中心焦点。
3. **重构修仙御空动力学与人物生动动画**:
   - 自然浮空呼吸波（12-16px 浮动，±2.5° 迎风微倾）。
   - 韩立脚下青竹蜂云剑灵光流转与气流喷射；极阴老祖脚下魔道紫炎翻滚。
   - 说话人高光聚焦：说话角色获得柔和灵光照亮，非说话角色轻微暗淡，视觉焦点明确。
   - 攻击动作：蓄力后撤聚气 -> 极速突进（带 3 重彩色发光残影与速度线）-> 命中顿挫 -> 优雅回位。
4. **华丽 Three.js & Canvas 仙侠法术特效**:
   - **九天玄雷**: 白炽主雷芯 + 蓝紫离子光晕 + 6-8 枝天穹分叉雷 + 劈中目标等离子爆球与地面冲击光环 + 瞬间天幕爆闪。
   - **青竹蜂云剑阵**: 14+ 柄金青飞剑沿三维贝塞尔螺线呼啸齐射，附带翡翠青光拖尾流带与击中爆破火星。
   - **破空月牙剑气**: 近身斩击斩出呼啸横掠的月牙能量刃，带有白光刃边与拖尾飞溅火星。
5. **导演分镜与电影级镜头推进**:
   - 说话时平滑推进至戏剧性中景/特写（1.4x - 1.55x），人物五官表情与口型自然醒目，保证同时兼容历史单元测试边界。
   - 战斗时斜角俯冲与冲击震屏。
6. **国风毛笔大字金边字幕排版**:
   - 金黄流光渐变字体，深朱砂与玄黑双重轮廓与投影，超强可读性。
   - 角色专属流光阵营印章（韩立翡翠青、极阴紫魔红、云飞碧天蓝）。
   - 句子进场 120ms 弹性微缩放 (popScale 1.06 -> 1.0)，节奏紧凑。
7. **缓存失效与全流程验证**:
   - 升级 `computeSceneHash` 的 `engineVersion`，失效低画质历史缓存。
   - 执行单元测试确保 100% PASS。
   - 实际渲染 `examples/animation-quality.txt` 生成新母带，提取关键帧图片直接自测视觉表现。
