# TASK-108: 小说文本分块、实体抽取与固定角色绑定状态机

## 1. 任务元数据
- **任务 ID**: TASK-108
- **状态**: DONE
- **优先级**: P1
- **所属模块**: `src/ai`
- **依赖任务**: TASK-102, TASK-103

---

## 2. 任务目标
构建鲁棒的小说文本分块状态机（`StoryParser`）。自动从自然段落中剥离台词与旁白描述，抽取说话人实体、受话人实体与动作关键词，并自动绑定至 `CharacterRegistry` 中的固定角色。

---

## 3. 详细设计与实现要求
1. **文本分块与对白抽取 (`src/ai/story-parser.ts`)**:
   - 准确识别中文引号（`“”`、`""`）内的台词，并分析引号前的说话人主语（如“魔道老祖厉声喝道：”）。
   - 提取段落环境描述、打斗动作动词（如“长剑出鞘”、“祭出万魂幡”）。
2. **角色实体映射状态机 (`src/ai/character-binder.ts`)**:
   - 结合别名与模糊匹配，将说话人准确绑定至 `CharacterProfile`（如“极阴”绑定至“魔道老祖”，“韩老魔”绑定至“韩天尊”）。
   - 未知角色自动标记需创建或使用通用占位符。
3. **单元测试 (`tests/story_parser.test.ts`)**:
   - 覆盖复杂对话、无主语连续对话、包含打斗动词的小说文本段落解析。
