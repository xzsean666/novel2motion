## 2. 任务目标
执行端到端全流程验证，从输入原始修仙小说文本开始，自动运行文本分块、角色锁定、AI 分镜编导、配音合成、自适应混音、Three.js 2.5D 舞台离线光栅化与流式 FFmpeg 压制，生成一段不少于 25 秒的爆款沙雕修仙推文动画母带，彻底验收画面质量（去娃娃化、真人魔性脸嵌合、无虚化硬边、毛笔金字描边卡点字幕与 3D 摄像机平滑运镜）。

---

## 3. 详细设计与实现要求

1. **测试用例文本 (`test_input.txt`)**:
   - 包含经典凡人修仙/魔道对峙沙雕剧情对白与旁白。
   - 涵盖 3 个以上角色出场（韩立/韩天尊、极阴祖师/黑煞教主、老道长/白发老者）。
   - 包含多情绪切换（震惊、冷酷、暴怒咆哮）与打斗场景（九天玄雷降临、青竹蜂云剑阵呼啸、白闪暴击）。

2. **全流程执行流水线**:
   - 运行纯后端 CLI 工具：
     ```bash
     node dist/cli.js render test_input.txt -o output/xianxia_master.mp4 --preset cinematic
     ```
   - 调度 `node-task-runtime` 多线程渲染与安全 FFmpeg 压制。
   - 验证分镜独立哈希缓存与断点续算。

3. **终极画质与视听指标验收**:
   - **画面清晰度与边缘**: 1080x1920 (9:16) 竖屏，PNG 纹理抗锯齿，无任何 AI 虚影或模糊雾气，硬边清晰。
   - **角色形象**: 彻底摒弃幼态 Q 版娃娃脸，全部采用 5.5 头身成男御剑飞行姿态，面部精准嵌合张学友魔性人脸贴图（自适应表情切换）。
   - **字幕质感**: 马善政毛笔行楷大字，金黄色渐变充填，深黑边缘描边，严格卡点对白音频波形。
   - **音画同步与避让**: 对白出现时 BGM 自动压低 -14dB，对白结束平滑回升，音效卡点精准。
   - **视频编码标准**: H.264 (yuv420p) + AAC (192kbps)，支持主流短视频平台直接上传。
